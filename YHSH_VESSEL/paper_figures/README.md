# paper_figures — 재구성된 논문 그림

`fig1_8_reorganization_plan.md` 에 맞춰, 흩어져 있던 지표별 개별 그래프를 그림마다
하나의 설계 질문에 답하는 복합 그림으로 다시 묶은 것.

```
python make_paper_figures.py          # Fig1~Fig8 전부
python make_paper_figures.py 2 5      # 일부만
```

출력은 이 폴더에 `FigN_*.png` 와 `FigN_*.pdf` (300 dpi, PDF 는 TrueType 임베드).

| 파일 | 역할 |
|---|---|
| `make_paper_figures.py` | 그림별 구성과 수치 |
| `figstyle.py` | 조건 색·막대·상대변화·패널 라벨 공통 |
| `schematics.py` | 개념도 (구조 4종 · 이웃 집계 · 방향성 벌점 · 혼합 함대) |

## 알려진 제약

**학습곡선은 넣지 않았다.** 막대는 학습이 끝난 뒤 정책을 고정하고 다시 항해시켜 잰
값이고, 곡선은 학습 중 로그를 결과 분포로 다시 계산한 값이다. 서로 다른 추정량이라
한 그림에 나란히 두면 같은 수치처럼 읽힌다 — 계획서의 공통 원칙이기도 하다. Fig1·Fig6
모두 결과 비교만 남겼고, 통신 투입 시점은 x축 라벨과 캡션이 전달한다.

(`_data` 가 없어 곡선을 다시 그릴 수 없다는 사정도 겹쳤다. 필요해지면 `embed_png` 가
`figstyle.py` 에 남아 있으므로 패널 하나만 추가하면 된다. Fig8 의 지도 패널이 그 방식이다.)

**개별 시드 점은 Fig7 에만 있다.** 시드별 값이 `_data` 에만 있기 때문이다. 계획서는
시드가 있는 조건에 점을 찍으라고 하지만, 없는 값을 지어내지 않는다는 원칙이 우선이다.
Fig6(c) 의 도착률만 시드 편차를 아는 값(±14.5 / ±1.4)이라 오차막대를 넣었다.

**Fig7 은 잠정이다.** 재집계 결과가 납품된 그림과 맞지 않는다 — 준수 43.4~45.1% 대
51.4~52.3%, 충돌 5.02~10.35% 대 1.08~2.60%, 시드도 5개 대 3개. 가중 방식은
`make_mixed_fleet.py` 의 `load()`/`fleet()` 과 동일하게 맞췄으므로 계산 차이가 아니다.
그림에 경고 문구를 넣어 두었다. **출처를 확정하기 전에는 정량 주장에 쓰지 말 것.**

**Fig7 x=0 이 없다.** 계획서는 통신 정상 함대를 x=0 에 넣기를 권하는데, `RawData` 에
그 조건이 없다.

**Fig8 은 (a) 만 실물이다.** (b)~(d) 는 재평가가 필요해 자리만 잡아 두었다. 계획서가
지정한 조건: 제안 체크포인트 `qd_MOE_SE`, `ring=0.7`, direct vs A*, 통신 OFF vs ON,
그리고 전체 320쌍과 막힌 148쌍을 분리 보고.
